# TrendNow

![TrendNow Banner](banner.png)

**Spot rising topics before everyone else piles in.**

TrendNow is a powerful Chrome extension for **Google Trends** analysis, trending topic discovery, rising keyword research, and early momentum tracking.

Perfect for creators, marketers, YouTubers, and trend hunters who want to find breakout topics early.

![TrendNow Dashboard](dashboard.png)

## ✨ Key Features

- Live Google Trends scanning
- Rising keyword discovery
- Country & Worldwide trend tracking
- Smart alerts and notifications
- Compact popup interface
- Trend scoring & signals

## Why Creators Love It

- Find hot topics **before** they explode
- Discover related rising searches instantly
- Get notified of new breakout trends
- Make better content decisions with data

## Tech Stack

- **Manifest V3** Chrome Extension
- JavaScript + modern web tech
- Backend: Next.js + Supabase

## Install (Load Unpacked)

1. Download or clone this repository
2. Open `chrome://extensions/` in Chrome
3. Enable **Developer mode**
4. Click **Load unpacked** and select the `Trendnow-public` folder
